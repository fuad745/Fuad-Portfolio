About

A developer who ships the whole thing.

I'm a self-driven full-stack developer based in Addis Ababa. I like owning a product end to end — the Flutter app in someone's hand, the Laravel API behind it, the Filament admin panel a team runs it from, and the deploy on whatever shared host the budget allows.

Most of my work lives where correctness matters: money math in integer cents, atomic transactions that can't double-pay, moderation flows built on trust and consensus. I care about the details that don't show up in a screenshot but decide whether software can be relied on.
